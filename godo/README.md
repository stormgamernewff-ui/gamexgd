# Whispering Pines 3D (Godot 4.3)

A 3D forest exploration game with physical sky lighting, distance fog, rolling terrain, fireflies, and 7 ancient relics to discover.

## Controls
- **Move:** WASD or Arrow Keys
- **Look:** Mouse (`ESC` toggles mouse cursor)
- **Sprint:** Shift
- **Jump:** Space
- **Toggle Lantern:** F

## Export to Windows `.exe` via GitHub Actions
1. Create a new GitHub repository and upload all files from this folder (including `.github/workflows/export.yml`).
2. Open the **Actions** tab on GitHub and wait for **Export Godot Game (.exe)** to finish (or click **Run workflow**).
3. Download **WhisperingPines3D-Windows-EXE** from **Artifacts** and run `WhisperingPines3D.exe`.
